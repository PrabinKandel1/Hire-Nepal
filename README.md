# Hire-Nepal 🇳🇵

**A recruitment platform prototype built to explore a better way to connect job seekers with opportunities in Nepal.**

Hire-Nepal is my second website project. I started building it in my free time because I wanted to explore a bigger idea than a typical portfolio website — a platform focused on connecting people with jobs and opportunities.

The project is a **working prototype**, built to explore the concept and demonstrate my web development skills. It is not a finished, production-ready recruitment platform.

## 💡 The Idea

Finding opportunities and connecting with the right people can be challenging. Hire-Nepal is my attempt to explore how a dedicated online platform could make that process more accessible and organized.

The long-term vision is bigger than the current implementation, and there is still plenty of room to improve, expand, and refine it.

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 🚧 Current Status

**Prototype — work in progress**

I developed Hire-Nepal independently in my free time. Because I had limited time to dedicate exclusively to the project and no team working alongside me, I couldn't take it as far as I originally imagined.

The website works as a prototype, but some parts remain incomplete, and the overall experience still needs refinement. It should be viewed as an exploration of an idea rather than a fully operational recruitment service.

## 🎯 What This Project Represents

- Turning an idea into a working website.
- Exploring the structure and user experience of a recruitment platform.
- Practising front-end development through a larger project.
- Learning by building independently and solving problems along the way.
- Identifying what needs to improve when taking a prototype toward a more complete product.

## 🚀 What's Next?

With more time, collaboration, and the right team, I would like to refine the user experience, strengthen the platform's functionality, and develop the concept further.

For me, Hire-Nepal is not just about what the website is today. It is also about the ideas I can explore, the problems I can work on, and what I can build when I have the opportunity to take a project further.
